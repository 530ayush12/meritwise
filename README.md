# Meritwise

Meritwise is a professional showcase for thoughtful iOS apps and articles focused on learning, technology, and well-being.

## Stack

- Next.js
- TypeScript
- Vercel

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deployment

This repository is intended to deploy automatically through Vercel from the `main` branch.

Production domain: `meritwise.xyz`
